# 个人知识库（持续更新）

把你想沉淀的短线知识、战法笔记、复盘心得放进本目录，**放一个 `.md` 文件即可自动入库**：
每次 `qa` 会话启动会比对文件指纹，新增/修改/删除都会增量重建检索索引，无需手动操作。

## 收录范围

- 本目录所有 `*.md` 文件（含子目录），自动成为知识库检索源
- 项目自带种子知识：`prompts/**`（各模块 prompt + 术语表）+ `docs/{需求分析,数据结构,战法规范}`
- 可选：`qa --with-reports` 把 `output/*_复盘.md` 也纳入（默认不纳入，防历史复盘污染检索）

## 切块边界

- 按 `##` / `###` 标题切分，章节名会作为 [来源] 展示
- 表格按行切（术语表「术语 | 定义」单行就是一个检索单元）
- 长段落按空行 / 约 700 字自动二次切

## 建议格式（推荐）

```markdown
## 某个主题

正文要点……（一个主题一个章节，方便检索命中）

### 小节

细节……
```

## 注意事项

- **不要提交敏感信息**（账户、密钥、未公开持仓细节等）——本仓库为公开仓库
- 术语新增先补 `prompts/glossary/术语表.md`，知识库会自动收录
- 已入库文件大幅重写后，检索到的片段会随增量重建自动更新
