## 3. 运行本项目（项目根目录执行）

包采用 `src/` 布局，运行前需把 `src` 加入模块搜索路径（`PYTHONPATH`）。

```bash
# Git Bash（本项目常用）
cd "e:/workspace/AI应用工具/每日复盘"
PYTHONPATH=src "E:/conda_envs/envs/mowan_dm/python.exe" -m daily_review kline --code 600000 --lmt 30
PYTHONPATH=src "E:/conda_envs/envs/mowan_dm/python.exe" -m daily_review realtime --codes 600601,002398,600789
# 端到端复盘：采集→指标→LLM 报告（涨停数据 15:00 后、龙虎榜 18:00 后完整；--no-llm 跳过 LLM）
PYTHONPATH=src "E:/conda_envs/envs/mowan_dm/python.exe" -m daily_review review --date 20260806
# 交互问答（v0.7）：RAG 短线知识库 + 数据工具；--ask 一次性提问，缺省进 REPL
PYTHONPATH=src "E:/conda_envs/envs/mowan_dm/python.exe" -m daily_review qa --ask "什么是炸板率？" --no-embedding
PYTHONPATH=src "E:/conda_envs/envs/mowan_dm/python.exe" -m daily_review qa --setup   # 装向量检索依赖+下载 bge 模型
# Web 工作台（v0.8，Flask）：战法管理 + 跑复盘 + 问答 + 数据看板（默认仅本机 127.0.0.1:5000）
PYTHONPATH=src "E:/conda_envs/envs/mowan_dm/python.exe" -m daily_review web --open
# 复盘指定个人战法（战法 ID 见 Web 战法管理页或 data/strategies/ 内 front-matter）
PYTHONPATH=src "E:/conda_envs/envs/mowan_dm/python.exe" -m daily_review review --date 20260806 --strategy strategy.user-xxx
# 图形启动器（v0.9，tkinter 窗口）：一键 Web 工作台 / 跑复盘 / 数据看板 / 问答；--dry-run 自检不弹窗
PYTHONPATH=src "E:/conda_envs/envs/mowan_dm/python.exe" -m daily_review launch
PYTHONPATH=src "E:/conda_envs/envs/mowan_dm/python.exe" -m daily_review launch --dry-run
```

> **复盘时机**：一般复盘在**下午 5 点之后**跑（龙虎榜盘后更新）；盘中/未更新日 `review` 仍可跑，龙虎榜章节自动降级为「未更新」说明。
> **盘中缓存自动作废**：当日数据在 15:00 前跑过会留下「盘中快照」缓存；同一日期 **15:00 之后**再跑 `review`/`dashboard` 时自动跳过该缓存强制重取（涨停/炸板/跌停池），避免收盘后重跑仍读到盘中陈旧数据。


> 可选：`python -m pip install -e .`（装进 mowan_dm）后即可免 `PYTHONPATH` 直接 `daily-review` 命令或 `python -m daily_review`。

### 图形启动器（v0.9）

- **双击 `启动.bat`**（项目根目录，ASCII 体无中文）→ 用 **pythonw.exe** 运行根目录 `launcher.py`（自插入 `src` 到 `sys.path`）→ 打开 tkinter 窗口（无控制台闪窗）
- 窗口内可一键启动：**Web 工作台**（常驻服务，用「停止」关闭）/ **跑复盘**（日期 + 无 LLM + 个人战法下拉）/ **数据看板** / **交互问答**（新控制台 REPL）；支持「创建桌面快捷方式」
- 桌面快捷方式 = pythonw 指向根 `launcher.py`（`.lnk` 无法设环境变量，故不依赖 `pip install -e`）；`创建` 由 PowerShell `-NoProfile -EncodedCommand`（UTF-16LE base64）写 Desktop
- 子进程统一用**控制台解释器** `python.exe`（pythonw 无 stdout）+ `PYTHONIOENCODING=utf-8` + `PYTHONUNBUFFERED=1`；管道捕获用 `CREATE_NO_WINDOW`，qa REPL 用 `CREATE_NEW_CONSOLE`
- 命令行等价：`python -m daily_review launch [--dry-run]`（`--dry-run` 打印解析出的环境与四条命令，不弹窗，可无头自检）
- 实现分层：`src/daily_review/launcher.py`（纯核心，不 import tkinter，可离线单测）+ `launcher_gui.py`（唯一 import tkinter 的 GUI 壳）

### LLM 报告（DeepSeek）前置

- 在项目根目录创建 `.env`（不入库，已 gitignore）写入：`DEEPSEEK_API_KEY=sk-xxx`
- 未配置 key 时：`review --no-llm` 仍可完整跑通数据采集 + 指标；带 key 的 `review` 才会调用 DeepSeek 生成 `output/{date}_复盘.md`；Web 复盘任务勾选「无 LLM」等价降级
- 密钥来源：用户私有，**禁止**提交/粘贴到仓库任何文件

## 5. Windows 注意事项

| 坑 | 说明 |
|---|---|
| **GBK 控制台编码** | 终端 print 含 emoji（如 ✅）会报 `UnicodeEncodeError`。CLI 已改用 GBK 安全字符；自己写脚本时避免非 GBK 字符 |
| **中文显示乱码** | Git Bash 显示中文可能 mojibake，属显示层问题，数据本身 UTF-8 无损（CSV 用 `utf-8-sig` 落盘，Excel 可直接打开） |
| **路径分隔符** | 代码内一律用 `pathlib.Path`；命令行用 `/` 或 `\` 均可 |
| **外部数据接口** | 东财/新浪接口需联网；UA 与 Referer 头已在 `data/http_client.py` 统一处理 |

## 6. 版本控制建议

- 加入版本库：`docs/`、`prompts/`、`src/`、`tests/`、`requirements*.txt`、`pyproject.toml`
- 不入库（已在 `.gitignore`）：`data/*/`、`output/*/`、`output/*.md`、`*.csv`、`.env`、`__pycache__/`、`.pytest_cache/`
- 新机器复现：创建 Python 3.14 conda 环境 → `pip install -r requirements.txt -r requirements-dev.txt` → `python -m pytest` 应全部通过
