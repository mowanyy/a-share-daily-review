# 东财接口清单 — 东方财富接口爬取

> 数据源选型：**东方财富接口爬取**（用户确认）。本文件列出所需接口、用途、字段与风险对策。
> 版本：v0.2（v0.2 已实现「东财 K 线」「新浪实时行情」，其余仍为待办）

---

## ⚠️ 总原则

1. **东财接口无正式文档**，接口路径与字段可能随时变更。实现时必须：字段映射集中在单一模块（见 `docs/数据结构.md`），所有返回值先校验再落盘。
2. 加 `User-Agent` 伪装浏览器、控制请求频率（≥1s/请求）、失败指数退避重试、按日缓存避免重复请求。
3. 数据仅在收盘后采集（A 股 15:00 后数据稳定）。

## 二、多日数据需求

以下分析依赖**跨日时序**，需把每日 #1/#2/#5/#7 结果落盘到 `data/{trade_date}/`：
- 连板晋级率：需要昨日涨停清单 → 今日对照
- 题材运行周期：需要题材成员数的**逐日变化**（启动=首现增多 / 发酵=扩散 / 高潮=达峰 / 退潮=减少）

实现时对历史日期做**回补抓取**（如一次性抓近 30 个交易日），并建立本地日线缓存。

## 三、风险与对策清单

| 风险 | 对策 | 触发说明 |
|---|---|---|
| 接口字段变更 | 字段映射集中 + 解析后 schema 校验 | 解析失败即报警 |
| 频率限制/IP 封锁 | 频率控制、UA 伪装、错误码重试、本地缓存 | 出现 403/空返回 |
| 盘中/停牌数据不稳 | 仅收盘后采集 | 15:00 后 |
| 新股/次新无题材 | 清洗规则集中定义 | 概念字段为空 |
| 交易日期（节假日/调休） | 交易日历本地化（东财 `get_trade_dates`） | 用于确定最近交易日 |
