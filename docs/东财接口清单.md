# 东财接口清单 — 东方财富接口爬取

> 数据源选型：**东方财富接口爬取**（用户确认）。本文件列出所需接口、用途、字段与风险对策。
> 版本：v0.5（池子/资金流/概念板块见 `data/eastmoney_pool.py`；龙虎榜/买卖席位见 `data/eastmoney_lhb.py`；K 线与实时行情见 v0.2 `data/eastmoney.py` / `data/sina.py`）

---

## ⚠️ 总原则

1. **东财接口无正式文档**，接口路径与字段可能随时变更。实现时必须：字段映射集中在单一模块（见 `docs/数据结构.md`），所有返回值先校验再落盘。
2. 加 `User-Agent` 伪装浏览器、控制请求频率（≥1s/请求）、失败指数退避重试、**主机轮换**（`push2 / 1./2.push2 / push2delay`）、按日缓存避免重复请求。
3. 数据仅在收盘后采集（A 股 15:00 后数据稳定）；盘中跑 `review` 数据不完整。

### 已验证的真实参数（2026-08-07 实测）

- **池子**：`getTopicZTPool?ut=7eea3edcaed734bea9cbfc24409ed989&dpt=wz.ztzt&Pageindex=0&pagesize=300&sort=fbt:asc&date=YYYYMMDD`（`date` 支持历史交易日）→ `data.pool[]`
- **单股历史资金流**：`push2his.eastmoney.com/api/qt/stock/fflow/kline/get?secid={1|0}.{code}&fields2=f51..f65` → klines 每行 `日期,主力净流入,小单,中单,大单,超大单`
- **全市场资金流（当日）**：`clist?fid=f62&fs=m:0+t:6,m:0+t:80,m:1+t:2,m:1+t:23&fields=f12,f14,f62,f66,f72`（f62=主力 f66=超大单 f72=大单；已核对超大单+大单=主力；⚠️ **2026-08-11 实测 `pz` 无论设多大每页固定只返回 100 行**，只含按主力净流入 Top-100，靠 `pn` 翻页才拿全）
- **龙虎榜每日榜单**：`datacenter-web.eastmoney.com/api/data/v1/get?reportName=RPT_DAILYBILLBOARD_DETAILSNEW&columns=ALL&source=WEB&client=WEB&pageNumber=1&pageSize=500&sortColumns=BILLBOARD_NET_AMT&sortTypes=-1&filter=(TRADE_DATE='2026-08-06')` → `result.data[]`
- **龙虎榜买卖席位**：`...reportName=RPT_OPERATEDEPT_TRADE_DETAILS&filter=(TRADE_DATE='2026-08-06')`（无股票过滤=当日全量，分页拉取；20260806 实测 603 条）
- **去重规则**（`analysis/lhb.py`）：一只股票因多个上榜原因出现多行 → 按代码去重，取**净额绝对值最大**的一条为准、原因列表合并；同一(股票,营业部)同理。避免多原因重复计数

> 具体 URL 与参数以 `src/daily_review/data/eastmoney_pool.py` 内实现为准。**每次上线前需验证接口可用性。**

## 二、多日数据需求

以下分析依赖**跨日时序**，需把每日 #1/#2/#5/#7 结果落盘到 `data/{trade_date}/`：
- 连板晋级率：需要昨日涨停清单 → 今日对照
- 题材运行周期：需要题材成员数的**逐日变化**（启动=首现增多 / 发酵=扩散 / 高潮=达峰 / 退潮=减少）
- 情绪温度（v0.5）：需要近 N 日（默认 5）的**涨停/炸板/跌停池**逐日数据，算各日温度分 → 阶段方向判定

> **v0.5 情绪温度时序抓取**：`pipeline.collect` 在已有近 N 日涨停池（`prev_pools`）基础上，逐日补拉炸板池/跌停池（`_fetch_opt` 容错，失败即该日 `zb_ok/dt_ok=False`）。请求量 ≈ 涨停池 1 + 炸板池 N + 跌停池 N（历史日期走 getTopicPool 的 `date` 参数，与当日同源）。

实现时对历史日期做**回补抓取**（如一次性抓近 30 个交易日），并建立本地日线缓存。

## 三、风险与对策清单

| 风险 | 对策 | 触发说明 |
|---|---|---|
| 接口字段变更 | 字段映射集中 + 解析后 schema 校验 | 解析失败即报警 |
| 频率限制/IP 封锁 | 频率控制、UA 伪装、错误码重试、本地缓存 | 出现 403/空返回 |
| 盘中/停牌数据不稳 | 仅收盘后采集 | 15:00 后 |
| 新股/次新无题材 | 清洗规则集中定义 | 概念字段为空 |
| 交易日期（节假日/调休） | 交易日历本地化（东财 `get_trade_dates`） | 用于确定最近交易日 |

## 四、采集层模块现状（v0.5）

```
src/daily_review/data/
├── http_client.py        # 请求封装：UA/超时/重试/指数退避
├── eastmoney.py          # 东财 K 线（v0.2）
├── eastmoney_pool.py     # 池子/资金流/概念板块（v0.3）：
│                          #   主机轮换 + ≥1s 节流 + 连续失败熔断
├── eastmoney_lhb.py      # 龙虎榜榜单/买卖席位（v0.4）：数据中心 datacenter-web 分页全量
├── hotmoney_seats.py     # 知名游资营业部名单（v0.4）：关键词子串匹配，人工维护可增补
├── repo.py               # data/{trade_date}/ CSV 落盘与读取（按交易日）
└── sina.py               # 新浪实时行情（v0.2）
```

交易日探测：`eastmoney_pool.resolve_recent_trade_dates` 拉涨停池判空回退，**免维护交易日历**。
历史日期资金流依赖 `push2his`（偶发限流，`push2delay` 兜底但仅当日）；当日资金流走 clist 批量（1 请求，但仅 Top-100）+ **v0.12 对 clist 拿不到的炸板股代码逐个 fflow 单股补齐**（实测 20260811 炸板 17 只全有数据）。DDX/分时大单：日线 DDX 与分时 DDX 均**无公开稳定接口**（tech/get、fflow/get、datacenter RPT_DDFX_*、pdfm JSONP 全 404/空壳），分时大单动向仅 `fflow/kline/get?klt=1`（240 点/日）可得，本次未接入。
