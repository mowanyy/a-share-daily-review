## 三、补数工具

```bash
# 1. 批量预生成/补采看板（zt/zb 缺则联网补，看板落盘 output/{date}_看板.html）
python -u -m tools.backfill_dashboards --days 60 --skip-data
# 2. 补指定日期（数据 + 看板）
python -u -m tools.backfill_dashboards --dates 20260910,20260911
# 3. 补龙虎榜/资金流（datacenter 历史可用；--fill-extra 慢，跑多少算多少）
python -u -m tools.backfill_dashboards --dates <列表> --fill-extra --skip-dashboards
# 4. 批量拉涨停股历史日K（回测价格数据；push2his 网络恢复后跑）
python -u -m tools.backfill_kline --lmt 1000 --sleep 1.2
# 5. 清理非交易日污染目录（仅删明确休市日）
python -u -m tools.backfill_dashboards --clean-junk
```

## 四、K 线数据格式（data/kline/{code}.csv）

```csv
trade_date,open,close,high,low,volume,amount,amplitude,pct_change,change,turnover
2026-07-31,9.59,9.51,9.59,9.28,1382638,1299502653.0,3.19,-2.06,-0.2,0.42
```
- 日线（klt=101）、默认不复权（fqt=0，`pct_change` 为真实涨跌幅，回测基于涨跌幅不受复权影响；如需前复权价格可 `--fqt 1` 重拉）
- 代码 6 位零填充（`600000`），股票池 = 7/22~9/11 全部涨停股去重
