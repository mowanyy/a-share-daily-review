# 需求分析 — 超短连板复盘系统

> 版本：v0.1 · 日期：2026-08-06 · 状态：已与用户确认核心决策

---

## 1. 项目背景与目标

面向 A 股**超短连板**交易风格的收盘复盘工具。用户在收盘后快速获得当日涨停生态的全景扫描，理解**连板梯队的晋级博弈**与**题材轮动节奏**，并借助 LLM 生成文字复盘与（未来）基于个人战法的**次日预案**。

核心价值：把散落在行情软件里的涨停数据，整理成「梯队 + 题材 + 资金 + 情绪」的**结构化复盘**，并让 AI 产出可读、可发布的 Markdown 复盘文章。

## 2. 业务术语（权威定义见 `prompts/glossary/术语表.md`）

| 术语 | 含义 |
|---|---|
| 连板 | 连续 ≥1 天涨停（含首板） |
| 连板梯队 | 按连板天数分层：首板、2板、3板…最高板（空间板） |
| 晋级 | 昨日 N 板，今日再涨停成为 N+1 板 |
| 断板 | 昨日涨停，今日未封涨停 |
| 炸板 | 盘中触及涨停后又打开 |
| 题材 | 推动涨停的炒作主题（概念/板块） |
| 龙头 | 题材内身位最高 / 封板最早 / 带动性最强的个股 |

## 3. 功能模块

### 3.1 首期模块（用户已拍板）

| 模块 | 说明 | 关键输出 |
|---|---|---|
| **连板梯队** | 当日涨停家数、连板高度、各级梯队个股列表 | 梯队表格 + 高度/晋级点评 |
| **题材运行周期与归类** | 涨停股按题材归类，判定题材运行阶段与龙头 | 题材归类表（阶段/龙头/助攻） |
| **炸板净流入** | 当日炸板股清单 + 个股资金净流入 | 按净流入排序 + 次日关注信号 |

### 3.2 未来扩展（架构预留）

| 模块 | 说明 | 预留方式 |
|---|---|---|
| **情绪温度** | 涨停数/晋级率/炸板率/连板高度 → 情绪周期量化（冰点/修复/高潮/退潮） | `module.*` 新增 prompt + 指标层 |
| **个人战法 → 次日预案** | 用户定义自己的战法，AI 依据战法给出次日预案（关注方向/梯队预案/风险） | `prompts/strategies/` 战法库 + `module.plan` |

## 4. 角色设计（LLM 两种用法都要）

### 4.1 报告模式
```
东财数据 → 清洗/结构化 → 各模块 prompt（module.*） → 拼接 → Markdown 复盘文档
```
- 各模块独立出章节，最终合并为一份完整复盘
- 系统角色：`prompts/system/复盘分析师.md`

### 4.2 问答模式
```
用户提问 → 按需调用数据工具（tool.*） → 问答助手 → 回答
```
- 数据通过工具函数按需获取（function-calling），不预先灌入全部数据
- 系统角色：`prompts/system/问答助手.md`

### 4.3 次日预案
```
当日复盘结果 + 用户战法 → module.plan → 次日预案
```

## 5. 数据需求

> 数据源：**东方财富接口爬取**（用户确认）。接口清单见 `docs/东财接口清单.md`。

- 涨停池（含连板数、封板时间、封单、炸板次数、所属概念）
- 炸板池、跌停池
- 题材/概念板块行情、概念成分股、概念资金流
- 个股资金流向（主力净流入）
- **多日历史数据**：连板晋级率、题材运行周期均需跨日时序

### 工程风险与对策
| 风险 | 对策 |
|---|---|
| 东财接口无正式文档、字段会变 | 数据模型层隔离（`docs/数据结构.md`），字段变更只改映射层 |
| 反爬/限流 | 频率控制、本地缓存、容错重试、UA 伪装 |
| 复权/停牌/新股等边界 | 数据清洗规则集中定义 |

## 6. 非功能需求

- **可扩展性**：新增复盘模块 = 新增一个 prompt + 一个数据接入，不改主流程
- **可维护性**：prompt 全部收敛在 `prompts/`，可版本化、可索引
- **术语统一**：语义以 `prompts/glossary/术语表.md` 为唯一权威
- **输出稳定**：Markdown 文档，可存档、可发布、可对比历史
