# 需求分析 — 超短连板复盘系统

> 版本：v0.7 · 日期：2026-08-10 · 状态：已与用户确认核心决策

---

## 1. 项目背景与目标

面向 A 股**超短连板**交易风格的收盘复盘工具。用户在收盘后快速获得当日涨停生态的全景扫描，理解**连板梯队的晋级博弈**与**题材轮动节奏**，并借助 LLM 生成文字复盘与（未来）基于个人战法的**次日预案**。

核心价值：把散落在行情软件里的涨停数据，整理成「梯队 + 题材 + 资金 + 情绪」的**结构化复盘**，并让 AI 产出可读、可发布的 Markdown 复盘文章。

## 2. 业务术语（权威定义见 `prompts/glossary/术语表.md`）

| 术语 | 含义 |
|---|---|
| 连板 | 连续 ≥1 天涨停（含首板） |
| 连板梯队 | 按连板天数分层：首板、2板、3板…最高板（空间板） |
| 晋级 | 昨日 N 板，今日再涨停成为 N+1 板 |
| 断板 | 昨日涨停，今日未封涨停 |
| 炸板 | 盘中触及涨停后又打开 |
| 题材 | 推动涨停的炒作主题（概念/板块） |
| 龙头 | 题材内身位最高 / 封板最早 / 带动性最强的个股 |

## 3. 功能模块

### 3.1 首期模块（用户已拍板）

| 模块 | 说明 | 关键输出 |
|---|---|---|
| **连板梯队** | 当日涨停家数、连板高度、各级梯队个股列表 | 梯队表格 + 高度/晋级点评 |
| **题材运行周期与归类** | 涨停股按题材归类，判定题材运行阶段与龙头 | 题材归类表（阶段/龙头/助攻） |
| **炸板净流入** | 当日炸板股清单 + 个股资金净流入 | 按净流入排序 + 次日关注信号 |
| **龙虎榜游资** | 龙虎榜榜单 + 买卖席位，识别知名游资动向与机构 | 上榜概览 / 净买排行 / 游资动向 / 次日关注 |
| **情绪温度** | 涨停数/空间板高度/晋级延续率/炸板率(反向)/跌停家数(反向) → 0–100 温度分 + 情绪周期（冰点期/修复期/高潮期/退潮期） | `analysis/emotion.py` 核算 + `module.emotion` 章节（报告第二章） |
| **数据看板** | 近 10 个交易日趋势图表（自包含单文件 HTML，纯 JS + 内联 SVG 画图，零外链/零 CDN）+ 顶部 LLM 多日趋势解读 | `dashboard.py` 生成 `output/{日期}_看板.html` + `module.dashboard` 解读（可 `--no-llm` 降级） |

### 3.2 未来扩展（架构预留）

| 模块 | 说明 | 预留方式 |
|---|---|---|
| **个人战法 → 次日预案** | 用户定义自己的战法，AI 依据战法给出次日预案（关注方向/梯队预案/风险） | `prompts/strategies/` 战法库 + `module.plan` |

## 4. 角色设计（LLM 两种用法都要）

### 4.1 报告模式
```
东财数据 → 清洗/结构化 → 各模块 prompt（module.*） → 拼接 → Markdown 复盘文档
```
- 各模块独立出章节，最终合并为一份完整复盘
- 系统角色：`prompts/system/复盘分析师.md`

### 4.2 问答模式（v0.7 已实现）
```
用户提问 → 混合检索知识片段（RAG）+ 按需调用数据工具（function-calling）→ 问答助手 → 回答
```
- **知识问答**：本地短线知识库（`prompts/**` + `docs/{需求分析,数据结构,战法规范}` + `knowledge/**`）混合检索出【知识片段】接地作答，可标注 [来源]；往 `knowledge/` 放 `.md` 即自动增量重索引（持续更新）
- **数据问答**：6 个数据工具（`tool.datatools` 契约，由 `kb/tools.py` 实现）按需取真实数据，不预先灌入全部数据
- 系统角色：`prompts/system/问答助手.md`；会话实现：`kb/qa.py`（详见 §4.5）

### 4.3 次日预案
```
当日复盘结果 + 用户战法 → module.plan → 次日预案
```

### 4.4 看板模式
```
近 N 日趋势（程序核算图表） + module.dashboard → 「多日趋势解读」一段
```
- 数据看板主体为程序核算的图表与表格，LLM 只负责顶部一段趋势解读
- 无 key / `--no-llm` / LLM 失败时降级为「（未生成解读）」，看板照常渲染

### 4.5 知识库（RAG，v0.7）

```
源: prompts/**（跳过 INDEX.md）+ docs/{需求分析,数据结构,战法规范} + knowledge/** (+可选 output/*_复盘)
   │  文件 sha256 指纹（.kb_cache/manifest.json）
   ▼
切块: 按 ##/### 标题 + 长段二次切 + 术语表「术语|定义」表格按行切  → Chunk
   ▼
索引: 关键词（sklearn char_wb n-gram(2,3)+cosine） + 向量（bge-small-zh 可选，缺省降级关键词）
   ▼ RRF(k=60) 融合
检索: 知识片段接地 → [来源: 文件 · 章节] → 问答助手引述
```

- **持续更新**：每次 `qa` 会话启动比对源文件 sha256，只重切/重编码变更文件；未变 chunk 的向量复用（`.kb_cache/` 不入库）
- **向量为可选增强**：`qa --setup` 安装 `sentence-transformers` + `modelscope` 并从 ModelScope 下载 bge 模型到 `models/`；未装/缺失自动降级纯关键词，功能不中断
- 数据类问题不走知识库数字，一律调用 §4.2 的数据工具取当日真实数据

## 5. 数据需求

> 数据源：**东方财富接口爬取**（用户确认）。接口清单见 `docs/东财接口清单.md`。

- 涨停池（含连板数、封板时间、封单、炸板次数、所属概念）
- 炸板池、跌停池
- 题材/概念板块行情、概念成分股、概念资金流
- 个股资金流向（主力净流入）
- **龙虎榜**：每日榜单 + 买卖席位（盘后 17:30 后更新）
- **多日历史数据**：连板晋级率、题材运行周期均需跨日时序

### 工程风险与对策
| 风险 | 对策 |
|---|---|
| 东财接口无正式文档、字段会变 | 数据模型层隔离（`docs/数据结构.md`），字段变更只改映射层 |
| 反爬/限流 | 频率控制、本地缓存、容错重试、UA 伪装 |
| 复权/停牌/新股等边界 | 数据清洗规则集中定义 |

## 6. 非功能需求

- **可扩展性**：新增复盘模块 = 新增一个 prompt + 一个数据接入，不改主流程
- **可维护性**：prompt 全部收敛在 `prompts/`，可版本化、可索引
- **术语统一**：语义以 `prompts/glossary/术语表.md` 为唯一权威
- **输出稳定**：Markdown 文档，可存档、可发布、可对比历史
