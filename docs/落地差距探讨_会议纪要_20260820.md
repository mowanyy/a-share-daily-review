## 二、三个推送的升级方案

### 1. 复盘推送（18:00）→ 卡片消息 + 核心指标 + 图表

飞书从纯文本升级为**卡片消息**，展示核心指标：

```

情绪温度：72（高温，近30日均值65）
涨停68家 / 炸板12家 / 跌停3家
空间板：5板（某某某）
主力资金净流入：芯片（+12亿）
龙虎榜：上榜15家，知名游资现身6家
连板梯队：5板1只 / 3板3只 / 2板8只 / 首板56只
```

- 可附带看板图表（图片形式推送）
- 时间充裕，内容丰富

### 2. 隔夜预案（07:30）→ 分层推送

| 消息类型 | 推送方式 |
|---------|---------|
| 影响复盘机会池个股的消息 | 详细内容（标题+摘要+分析） |
| 与复盘机会池无关的消息 | 只给标题（客户知道有这回事，竞价验证再决定） |

**重大消息判断标准**：不是看消息本身多重要，而是看它是否影响到了**复盘机会池中的个股**。

### 3. 开盘策略（09:25）→ 二级筛选逻辑

```
复盘机会池 + 隔夜消息影响 → 竞价换手率排名 → 符合条件的才推
```

- **筛选指标**：竞价换手率（竞价成交量 ÷ 流通股本）
- **筛选方式**：对机会池（复盘+隔夜预案关联的股票，约10-30只）算竞价换手率，取最高的前几只推送
- **未来升级**：全市场竞价换手率排名，取交集（方案B）

### 4. 市场温度指数（附加）

情绪温度与历史数据对比（近30日、近一年），帮助客户判断当前市场位置。
