# 基金风格 Skill 档案使用说明（v0.17）

> 本项目内建的一组「基金风格 skill」：把网上公开的知名基金经理投资风格整理成**可判定规则档案**，
> 供你在本项目会话中让 AI 以某风格分析个股/板块/基金持仓。**仅限本项目内使用**，
> 不注册为用户级 `/命令`、不写入 workspace 之外。

## 档案清单（`skills/fund-styles/`）

| 文件 | name | 风格一句话 |
|---|---|---|
| `深度价值-张坤型.md` | fundstyle-deep-value-zhangkun | 优质公司 + 合理价格 + 长期持有（ROE/自由现金流/消费龙头） |
| `景气成长-刘格菘型.md` | fundstyle-growth-liugechong | 产业趋势 + 景气度排序，容忍高波动换高成长 |
| `低估值-丘栋荣型.md` | fundstyle-value-qiudongrong | PB-ROE 框架，便宜且变好，等待价值回归（可反向猎错杀） |
| `医药成长-葛兰型.md` | fundstyle-medical-gelan | 长线重仓医药高景气细分龙头，淡化短期波动 |

每个档案统一 6 节结构：**风格画像 → 核心判断清单（可判定指标阈值）→ 选股规则 → 买/卖/持有纪律 → 反例（何时不适用）→ 分析输出格式建议**。

## 怎么用

在这套系统的会话里直接说，例如：

- 「以**张坤风格**分析 600519 贵州茅台，值不值得买？」
- 「用**刘格菘景气成长**视角看新能源板块现在处于什么位置？」
- 「按**丘栋荣低估值**框架筛一遍我概念池里的票，哪个是价值陷阱哪个是错杀？」
- 「以**葛兰医药风格**分析这只基金前十大重仓的景气度。」

AI 会读取对应档案，按里面的阈值清单逐项核对、指出缺失数据、给明确结论与操作倾向，而不是泛泛而谈。

## 使用节奏（重要：周K / 月K，不是日K）

基金风格是**中长线定价逻辑**，只在**周K / 月K** 层面做判断，**不用日K 做风格决策**（日K 波动是噪音，超短情绪归每日复盘战法管）。每个档案第 0 节「时间周期与触发时点（先读）」内置了这套方法论，建议按下面节奏用：

| 触发时点 | 周期 | 做什么 | 示例说法 |
|---|---|---|---|
| **每周一** | 周K | 周K 视角复盘：中期趋势、关键支撑/阻力、周成交量、风格的指标在周线的变化 → 「本周操作倾向」 | 「今天周一，按**张坤风格**用**周K** 复盘一下我概念池里消费方向的票」 |
| **每月 1 号** | 月K | 月K 视角复盘：长线趋势与估值分位、上一月景气/基本面/政策核对 → 「本月持有/调仓倾向」 | 「月初了，用**丘栋荣低估值**风格按**月K** 看这些仓位该不该调」 |

- 各风格的周期侧重不一（档案第 0 节已写明）：张坤型**月K 定估值、周K 找买点**；刘格菘型**月K 定景气阶段、周K 找加速点**；丘栋荣型**月K 定估值分位、周K 找左侧买点**；葛兰型**月K 定景气与政策、周K 选龙头买点**。
- **数据从哪来**：本系统 CLI 直接拉周/月K——
  ```bash
  "E:/conda_envs/envs/mowan_dm/python.exe" -m daily_review kline --code 600519 --klt 102 --lmt 60   # 周K（约60周）
  "E:/conda_envs/envs/mowan_dm/python.exe" -m daily_review kline --code 600519 --klt 103 --lmt 48   # 月K（约48个月）
  ```
  （`klt`：101=日线 102=周线 103=月线）分析时优先用这些真实周/月K 数据，拿不到就明说「数据不足」，**禁止用日K 冒充周/月K 结论**。
- 错过时点没跑？补做可以，但结论里要标注实际所看周期与日期，方便回看对照。

## 与复盘战法的区别

| | 基金风格 skill | 复盘战法（strategy.*） |
|---|---|---|
| 逻辑 | 中长线定价（ROE/估值/景气/现金流） | 超短连板情绪（封单/梯队/炸板/竞价） |
| 用途 | 独立分析视角，判断「值不值得买、是不是坑」 | 驱动每日「七、次日预案」选短线机会 |
| 节奏 | 季度/年级 | 隔日/日内 |

两者互为补充：风格档案帮你**判断一家公司的成色**，战法帮你**决策明天的买卖**。
如果你想从某风格中**提炼一套短线规则**（比如「消费龙头杀到 PE<20 且当日首板异动才介入」），
可以把它写成战法正文，走 Web 战法管理页新增/编辑保存，再在跑复盘时选中驱动次日预案。

## 一键进战法库

在 **Web 战法管理页**点「导入 SKILL.md」，粘贴其中一个档案全文（含 front-matter），即以导入为个人战法
（`strategy.user-<hash>`，正文原样保留、缺节仅提示）。也可用 CLI：

```bash
"E:/conda_envs/envs/mowan_dm/python.exe" -m daily_review skill import skills/fund-styles/深度价值-张坤型.md
"E:/conda_envs/envs/mowan_dm/python.exe" -m daily_review skill export strategy.user-xxx --out out.skill.md
```

注意：基金风格是长线逻辑，直接驱动「次日预案」会和超短系统语义打架，
**导入后建议先编辑改写成短线可判定规则**再启用。

## 为什么建在项目里

- skill 只放本项目 `skills/`（git 入库、随项目走、他人可得），不污染你的个人 skill 目录；
- 文件同时被问答知识库收录（`kb/corpus.py` 已含 `skills/**`），在 Web「问答」页问「张坤风格看股票看什么指标」也能检索到；
