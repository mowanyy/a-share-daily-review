# 术语表 — 超短连板统一语义

> 本项目所有 prompt、文档中的术语定义**以本表为唯一权威**。新增术语先在此登记，再到使用处引用。

## 涨停 / 连板基础

| 术语 | 定义 |
|---|---|
| 涨停 | 当日收盘价触及涨幅上限（主板 10%、创业板/科创板 20%、北交所 30%） |
| 连板 | 连续 ≥1 个交易日涨停（首板记为 1 连板） |
| 首板 | 当日第 1 个涨停（1 连板） |
| 空间板 / 最高板 | 当日连板数最高的个股 |
| 高度 | 当前连板数的最高值（如「空间板 5 板」= 高度 5） |

## 晋级博弈

| 术语 | 定义 |
|---|---|
| 晋级 | 昨日 N 板，今日再涨停成为 N+1 板 |
| 断板 | 昨日涨停，今日未再封涨停 |
| 晋级率 | 某层级昨日涨停股中今日晋级的比例（如 3进4 = 昨日 3 板今日上 4 板） |
| 溢价 | 昨日涨停股今日相对昨收的竞价/开盘平均涨幅 |
| 掉队 | 同题材连板股中断板、未跟上龙头身位 |

## 封板质量

| 术语 | 定义 |
|---|---|
| 封板 | 涨停价有巨量买单封死 |
| 封单 | 涨停价挂买单金额（封单越大越稳） |
| 封板时间 | 首次封死涨停的时间（越早越强） |
| 炸板 | 盘中触及涨停后打开 |
| 回封 | 炸板后再次封回涨停 |
| 炸板率 | 炸板家数 /（涨停家数 + 炸板家数） |

## 情绪周期

| 术语 | 定义 |
|---|---|
| 冰点期 | 涨停家数骤减、高度极低、晋级率差，观望为主 |
| 修复期 | 涨停家数回升、晋级率回暖，可试探性做多 |
| 高潮期 | 涨停家数、高度、晋级率共振达峰，最强但风险积累 |
| 退潮期 | 家数与高度同步下降、炸板率升高，兑现避险 |
| 情绪温度 | 0–100 量化指标（涨停数/高度/晋级率/炸板率合成，未来模块） |

## 题材与龙头

| 术语 | 定义 |
|---|---|
| 题材 / 概念 | 推动涨停的炒作主题（板块） |
| 主线 | 涨停家数最多或高度最高的核心题材 |
| 分支 | 跟随主线的小题材（常一日游） |
| 龙头 | 题材内身位最高 / 封板最早 / 带动性最强的个股 |
| 助攻 | 同题材跟随涨停的个股 |
| 卡位 | 同身位个股抢先封板取代原预期龙头 |

## 风险黑话（读复盘时常见）

| 术语 | 定义 |
|---|---|
| 大面 | 大幅亏损（如天地板吃面） |
| 天地板 | 涨停开盘一路砸到跌停 |
| 核按钮 | 竞价/早盘恐慌性核按砸盘出逃 |
| 承接 | 分歧时有资金接盘使价格企稳 |
| 分歧转一致 | 从多空分歧转为一致看多（常见加速信号） |
