# 模块 Prompt：情绪温度

## 输入数据（由程序提供，勿自行编造）

- **情绪温度(已核算)**：`score`（0–100）/ `stage`（冰点期/修复期/高潮期/退潮期）/ `stage_reason`（依据句）/ `score_series`（近 N 日温度序列 `[{date, score}]`，最新在前）/ `days_used`
- **成分分(已核算)**：`components`（今日各维子分 0–100：`zt` 涨停家数 / `height` 空间板高度 / `promote` 晋级延续率 / `break` 炸板率(反向) / `dt` 跌停家数(反向)）
- **原始输入**：`raw`（`zt_count` / `max_lb` / `promote` / `break_rate` / `dt_count`）
- **缺失说明**：`notes[]`（盘中预览 / 某维数据缺失未计入 / 序列缺日等）

> 阈值与权重由程序配置；温度分与阶段由程序核算，**禁止自行重算**。
> 晋级延续率 = 全部昨日涨停股今日再封涨停的比例（整体口径），与「连板梯队」的分档晋级率（如 3进4）不同，本章只出现整体口径一个。

- **数据可用性**：`数据可用性`（布尔值）与`数据说明`（字符串）。若`数据可用性`为 false，**必须输出「数据缺失：{数据说明}」**，不得编造数字。
## 核心逻辑

1. **情绪温度是市场级定位**：先于模块证据章节，回答「今天市场整体情绪处于什么位置、什么方向」。
2. **温度分与阶段由代码核算**，你只做呈现与解读：禁止重算温度分、改写阶段词或另造依据句。
3. **两套阶段词并存不可混用**：情绪周期（冰点期/修复期/高潮期/退潮期，带「期」）是市场级；题材运行阶段（启动/发酵/高潮/退潮，裸词）是题材级。

## 输出结构

### 1. 温度与阶段一行（必须原样引用程序核算结果）
示例：`情绪温度 62 分 / 周期 修复期。依据：近5日情绪温度 45→52→58→60→62，今日 62 分（较昨日 +2），判定修复期`

### 2. 成分拆解表
| 成分 | 今日值 | 成分分(0–100) |
|---|---|---|
| 涨停家数 | 60 | 40 |
| 空间板高度 | 5 板 | 63 |
| 晋级延续率 | 35% | 70 |
| 炸板率（反向） | 20% | 83 |
| 跌停家数（反向） | 5 | 83 |

- 指出驱动温度分的主要成分（1–2 个），解释分差来源

### 3. 近 N 日温度走势与位置
- 用 `score_series` 一句话描述趋势（连续回升 / 高位回落 / 冰点横盘）
- 静态定位：0–44 冰点区 / 45–69 修复区 / 70–89 高潮区 / 90+ 过热（过热属高潮区修饰语，不另设阶段）

### 4. 次日基调（1 句）
- 市场级仓位倾向，`若…则…` 条件式（如「若明日涨停家数继续放量且高度抬升，则情绪处于修复上行，可积极试错；若炸板率再度升高，则修复可能夭折」）
- 方向/标的具体预案**留给次日预案章节**，本章不展开

## 输出纪律

- 温度分/阶段/依据句必须原样引用，禁止重算、改写或另造
- 数据缺失（`notes`）标注「缺数据」，不臆测
- 阶段词只用带「期」的市场级词；不重复连板梯队/炸板章节的明细
- 数字精度与输入一致；术语按 `glossary/术语表.md`
