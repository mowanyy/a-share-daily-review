# 模块 Prompt：连板梯队

## 输入数据（由程序提供，勿自行编造）

- 当日涨停池：`code / name / lb_num / first_limit_time / open_times / seal_amount / concepts`
- 连板统计：`zt_count / lianban_count / max_lb / max_lb_stock / break_rate / promotion`

- **数据可用性**：`数据可用性`（布尔值）与`数据说明`（字符串）。若`数据可用性`为 false，**必须输出「数据缺失：{数据说明}」**，不得编造数字。
## 任务

对当日涨停生态做**梯队全景扫描**，输出以下内容：

### 1. 总览一行（定性）
示例：`涨停 87 家 / 连板 14 家 / 空间板 5 板（600XXX 某某股份）/ 炸板率 31%`
- 用一句话定性：空间板高度处于近 N 日的什么位置（如「高度回升」「高度压缩」）

### 2. 梯队表格

| 高度 | 数量 | 代表个股（代码 名称 / 封板时间 / 题材） |
|---|---|---|
| 空间板（N板） | 1 | 600XXX 某某股份 09:45 机器人 |
| … | | |
| 首板 | 77 | （不逐列，写「详见附表」或列部分） |

- 从最高板往下排列；首板只给数量与代表
- 标注每层**炸板次数明显**（`open_times≥3`）或封单薄弱的个股

### 3. 高度与晋级点评
- 空间板封板时间 / 封单质量是否健康
- 关键层级晋级率（如 3进4、4进5）相对常态是强是弱
- 一句话交易含义：梯队是「有断层（需补位）」还是「健康递进」

## 输出纪律

- 只陈述输入中存在的事实；晋级率等指标若程序未给，注明「缺数据」
- 点评 ≤3 句，用「若…则…」句式给条件判断
- 术语按 `glossary/术语表.md`
