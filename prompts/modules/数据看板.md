# 模块 Prompt：数据看板（多日趋势解读）

## 输入数据（由程序提供，勿自行编造）

- **近N日趋势**：`trend`（旧→新，N 行 `[{date, zt_count, lianban_count, max_lb, break_count, break_rate, dt_count, emotion, missing}]`）
  - `emotion` 为当日情绪温度分（缺日可能为 `null`）；`missing` 为缺数据标记（`涨停缺失`/`炸板缺失`/`跌停缺失`）
- **今日结构摘要**：`KPI`（今日涨停/连板/空间板/炸板率/跌停家数）、`情绪温度(已核算)`（score + stage + stage_reason）、`主要题材`（≤5 个：名称/家数/最高身位/阶段/龙头）、`炸板概览`（炸板家数 + 重点炸板）、`龙虎榜`（上榜家数 + 知名游资标签）

> 趋势行由程序逐日核算；温度分与阶段由程序核算，**禁止自行重算或编造缺日数字**。

## 任务

1. 读趋势：用 **2–4 个数据点**概括 N 日走势——家数（涨停/连板）升降、空间板高度变化、炸板率高低、情绪温度分段移动，指明趋势方向（升温 / 降温 / 横盘）。
2. 定位今日：点名今日所处**情绪周期阶段位置**（见术语表「情绪周期」，只用带「期」的市场级词）。
3. 点背离/转折：若某维与整体趋势不一致（如家数升但高度降、温度升但炸板率也升），点出一句。
4. 缺数据日注明「缺数据」，不臆测。

## 输出结构

**只输出「多日趋势解读」正文一段（150–250 字）**，结构与序如下：
- 第 1 句：趋势总括（1 个方向性判断 + 1–2 个数据点佐证）
- 第 2–3 句：分段细节（高度/炸板率/温度各自一句话，各带 1 个数据点）
- 第 4 句：今日阶段定位 + 背离/转折提示（若无背离可省略）

## 输出纪律

- **只输出正文一段**：不加标题、不加 Markdown 标记、不加「解读：」前缀、不换行分点
- **禁止重算**：所有数字照抄输入；温度分/阶段/依据句原样引用「情绪温度(已核算)」
- **禁止编造**：缺数据日明确写「缺数据」，不补数值、不臆测走势
- 阶段词只用带「期」的市场级词（冰点期/修复期/高潮期/退潮期）；题材级裸词不用于本段
- 术语按 `glossary/术语表.md`
