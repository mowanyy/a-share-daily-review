# 模块 Prompt：次日预案（战法驱动）

## 输入数据

- 当日复盘结构化结果：情绪温度（`score`/`stage`/`stage_reason`）、连板梯队、题材周期、炸板资金、龙虎榜游资（前五章结论）
- 用户指定的**战法**（`strategy.*`，按 front-matter 中的规则执行）
- 若未指定战法，退回**通用预案**（见下）

- **数据可用性**：`数据可用性`（布尔值）与`数据说明`（字符串）。若`数据可用性`为 false，**必须输出「数据缺失：{数据说明}」**，不得编造数字。
## 任务

基于当日复盘 + 战法规则，输出**次日（下一交易日）的可执行预案**。

## 输出结构

### 1. 次日核心观点（1 段）
- 以**情绪温度/周期**（程序核算，原样引用）为基调：情绪大概率处于什么位置（延续/分歧/修复）
- 一句话：明天是「做强」还是「避险」的基调

### 2. 关注方向（按战法触发条件）
- 列出 1–3 个方向：题材 + 具体对象（代码 名称）+ 观察信号
- 每个对象给出**符合战法的触发/买入条件**（如「早盘 30 分钟封板且封单>1 亿」）
- 对象优先级按战法的选股规则排序

### 3. 梯队预案（晋级 / 断板两情形）
- 空间板或核心标的若**晋级** → 关注什么（跟随/套利）
- 若**断板/大面** → 该怎么做（减仓/回避/切换哪条线）
- 用「若…则…」条件句，逐对象给出

### 4. 风险警示
- 战法内「规避与风险」章节的反例条件逐条核对，命中则明确警示
- 数据不足无法判定的点，明说缺什么

## 战法执行规则

1. **只执行用户指定的战法**，不自行混合其他战法逻辑
2. 战法中的「触发条件」若输入数据不足，**明确标注缺失数据**，不臆测
3. 战法要求禁止的行为（反例）一律不输出
4. 通用预案（未指定战法时）：仅给方向与风险，不给具体买卖点

## 输出纪律

- 预案是「条件触发」式的，不是确定性预测
- 每个建议都注明依据（战法哪一条 / 当日哪个数据）
- 语言克制，不渲染焦虑或狂热
