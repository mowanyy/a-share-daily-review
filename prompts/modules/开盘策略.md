# 模块 Prompt：开盘策略（竞价筛选个股）

## 输入数据

- 昨日复盘结构化结果：连板梯队、题材周期、情绪温度（已核算摘要）
- **隔夜预案全文**（今日开盘前生成的关注方向）
- **竞价数据**：昨日涨停池 + 预案关注股的竞价表现（JSON 列表，含 `code`/`name`/`auction_pct`(高开幅度)/`auction_volume`(竞价量)/`auction_ratio`(量比)/`prev_seal`(昨日封单)）
- 若指定战法（`strategy.*`），按战法规则筛选

- **数据可用性**：`数据可用性`（布尔值）与`数据说明`（字符串）。若`数据可用性`为 false，**必须输出「数据缺失：{数据说明}」**，不得编造数字。
## 任务

在**竞价结束后（9:25-9:30）**，基于竞价实际表现，**只筛选真正有机会的个股**，输出开盘前 3 分钟的执行清单。此刻聚焦个股，不做泛泛的方向论述。

## 输出结构

### 1. 竞价总览（1 段）
- 昨日涨停/连板股竞价整体表现：高开家数占比、连板股竞价平均涨幅、情绪温度在竞价端的映射
- 一句话：今日竞价情绪是「延续」还是「分歧/退潮」

### 2. 有机会的个股清单
- **只列出符合条件的机会股**，逐只给出：
  - 代码 名称 / 竞价涨幅 / 竞价量比 / 昨日封单
  - 触发条件（结合隔夜预案 + 战法，如「竞价高开 3%-6% 且量比放大」）
  - 操作建议（若…则…的条件句）
- 排序：空间板/龙头优先，其次主线题材连板，再次首板补涨
- **不及预期/兑现的标的明确标注「回避」**，不强行造机会

### 3. 开盘执行提示
- 开盘 3 分钟注意事项（竞价封单骤减、炸板、题材切换等）
- 持仓股的竞价处理（去留信号）
- 若无符合条件的机会，明确写「今日无符合战法机会，空仓观望」

## 输出纪律

- **只列有数据支撑的机会股**，不编造买点、不给无依据的目标价
- 竞价数据不足无法判定的标的，明确标注「数据不足」
- 每个建议注明依据（竞价哪个指标 / 隔夜预案哪条 / 战法哪条）
- 语言克制，不渲染「买入」狂热
