# 模块 Prompt：龙虎榜游资

## 输入数据（由程序提供，勿自行编造）

- **龙虎榜概览**：`stock_count` 上榜股票数 / `total_net_amt` 净买总额 / `total_buy_amt` 买入总额 / `total_sell_amt` 卖出总额 / `reason_dist` 上榜原因分布（[{reason,count}]）/ `inst_stock_count` 机构上榜股数
- **个股净买排行**：`net_rank`（按净买额降序 TOP 15）— `code / name / change_rate / turnover_rate / net_amt / buy_amt / sell_amt / reasons / reason_types / buy_seats / sell_seats / is_zt / lb_num`
- **知名游资动向**：`hotmoney` — `tag`（游资名号）/ `style` / `style_cn` / `net_amt` 当日净买总额 / `buy_amt` / `stocks[]`（`code / stock_name / act_buy / act_sell / net_amt / reason / change_rate / is_zt / lb_num`）
- **活跃席位**：`active_seats`（当日净买额 TOP 15 营业部，含游资标签）— `seat_name / code / stock_name / act_buy / act_sell / net_amt / tag / style_cn`
- **涨停联动**：`zt_cross` — 上榜且当日涨停/连板股（`code / name / change_rate / net_amt / reasons / lb_num`）
- **次日关注**：`watch` — 程序已筛出的关注候选（`tag / code / name / net_amt / change_rate / lb_num / is_zt`）

> 数据口径：个股/席位因多个上榜原因重复的，程序已按**净额绝对值最大的一条**去重（见 `docs/东财接口清单.md`），输出中直接使用，不要自行加总。

## 核心逻辑

1. **龙虎榜是情绪与资金的交叉验证**：涨停/连板股上龙虎榜 = 资金认可；上榜但资金净流出 = 分歧。
2. **游资是打板生态的核心玩家**：知名游资的买/卖方向、风格（打板/趋势/量化）决定次日溢价预期；机构净买入是中线背书，与游资短线视角不同。
3. **拉萨系（散户通道）不是游资**：识别为「散户集中营」，出现大量拉萨席位通常意味着筹码分散、次日抛压大。

## 输出结构

### 1. 上榜概览
- 上榜股票数、净买总额、机构上榜股数
- 上榜原因分布 Top 3（偏离值 / 换手 / 连板累计），一句话定性今日龙虎榜氛围（资金进攻/分歧/撤退）

### 2. 净买排行（按净买额降序，Top 10 表格）

| 代码 名称 | 涨幅 | 净买额 | 上榜原因 | 涨停/连板 | 买卖席位数 |
|---|---|---|---|---|---|
| 002428 云南锗业 | +10.0% | +11.5亿 | 3日偏离20% | 否 | 11/11 |

### 3. 知名游资动向（本章重点）
- 每个出场游资一段：名号 + 风格 + 当日净买总额 + 具体标的（净买方向）
- 只写**确有席位数据**的游资；未上榜不写
- 识别为散户通道（拉萨系）的单独说明，不当作游资

### 4. 活跃席位
- 当日净买额 TOP 5 营业部及其风格标签（含未知席位：标注「新席位」）
- 若同一游资多席位共振，合并说明

### 5. 游资 × 连板联动
- 上榜且当日涨停/连板股的游资构成：是否有知名游资进场接力、机构是否参与

### 6. 次日关注
- 从 `watch` 候选里挑 1–3 个：游资名号 + 标的 + 观察条件（「若高开缩量则…」）
- 全部条件句式，注明依据（当日哪个数据）

## 输出纪律

- 只列输入数据中确实出现的游资与个股；无数据标注「无知名游资上榜」
- 金额用「亿/万」中文单位；`net_amt` 为负表示净卖出，写明方向
- 游资风格按 `style_cn` 原文引用，不自行发明标签
