> 本档案基于公开的基金经理风格总结整理（广发刘格菘：景气度投资、产业趋势），仅供参考、不构成投资建议。

## 0. 时间周期与触发时点（先读）

本风格是**中长线定价逻辑**，只在 **周K / 月K** 层面做判断；**不用日K 做风格决策**（日K 波动属噪音，超短情绪逻辑交给每日复盘战法）。

- **每周一 → 周K 视角**：用周K 看产业趋势的**确认与加速**（周K 放量上攻、连续数周新高、周线均线多头排列），核对本清单指标在周线数据上的最新变化，输出「本周操作倾向」。
- **每月 1 号 → 月K 视角**：用月K 看景气度所处阶段（月度涨幅/量能、连续月线趋势、景气拐头迹象），核对上一月的行业景气、增速与估值容忍度，输出「本月持有/调仓倾向」。
- 本风格周期侧重：**月K 定景气阶段，周K 找趋势加速点**；高波动赛道允许周内大幅震荡，不以单日表现定去留。
- 数据来源：本系统 `kline --klt 102`（周K）/ `klt 103`（月K）拉取；无周/月K 数据时明确标注「数据不足」，不以日K 模拟代替。
- 输出必须标注所看周期（周K 或 月K）与触发点（周一 / 月初），便于回看验证。

## 1. 风格画像

- 一句话：**买产业趋势向上的成长股，用景气度排序，容忍高波动换高回报**。
- 特征：行业集中度高（单赛道重仓）、持股周期偏中长（季度级别）、不太看估值高低、更看重收入和利润的**增长斜率**。
- 行业偏好：新能源（光伏/锂电/储能）、半导体、军工、科技制造等**渗透率提升 / 技术迭代**中的成长赛道。

## 2. 核心判断清单（可判定指标）

| 维度 | 标准 | 说明 |
|---|---|---|
| 行业景气度 | 行业收入/利润增速处于上行周期（营收增速 30%+ 优先） | 景气是第一排序，排在估值前面 |
| 渗透率 | 渗透率不高、仍处快速提升期（而非已饱和） | 饱和赛道不是成长 |
| 公司增速 | 营收/净利增速 ≥30% 且向上（环比加速更佳） | 增速减速要警惕 |
| 订单/产能 | 在手订单、扩产、行业资本开支数据验证景气 | 无数据明说缺 |
| 估值容忍 | 高景气时接受高估值（PEG 可 >1.5），但拒绝情绪透支 | 博傻阶段退出 |

## 3. 选股规则

1. 先选行业再选股：景气度排序 → 选该赛道**弹性最大、最纯正**的标的（次新龙头常比老白马弹性大）。
2. 只买**增速与景气共振**的公司；增速掉队的坚决换掉。
3. 回避「景气见顶但股价还在讲故事」的板块（如行业景气已拐头、库存已在去化末端）。

## 4. 买 / 卖 / 持有纪律

- 买入：行业景气确认上行 + 个股增速兑现 + 股价未过度透支；不打一枪就全仓，分批。
- 卖出条件：① 行业景气度见顶回落（增速拐点、政策/需求证伪）；② 个股增速连续 2 个季度下滑；③ 估值到情绪泡沫区（市场一致性看多、散户占比飙升）。
- 持有：允许单赛道 30%+ 波动，不因日内/周线波动离场；组合内多赛道分散对冲单一行业风险。

## 5. 反例（何时不适用本风格）

- 低增长、稳定分红的价值股（银行/白酒慢速期）——风格错配。
- 纯事件驱动、无基本面增速支撑的题材连板——不适用。
- 行业景气已进入衰退段却仍高估值——危险区，回避。

## 6. 分析输出格式建议

1. **景气判断先行**：该行业/公司当前处于景气周期的哪个位置（上行中段/加速/见顶?），依据是什么（增速/订单/价格）。
2. **增速核对表**：营收/净利同比与环比、近四季趋势。
3. **估值与情绪**：是否已透支、情绪指标（换手、机构一致性）。
4. **操作倾向**：买入/持有/退出 + 跟踪的景气领先指标。
