> 本档案基于公开的基金经理风格总结整理（中欧葛兰：医药赛道投资、高景气龙头），仅供参考、不构成投资建议。

## 0. 时间周期与触发时点（先读）

本风格是**中长线定价逻辑**，只在 **周K / 月K** 层面做判断；**不用日K 做风格决策**（日K 波动属噪音，超短情绪逻辑交给每日复盘战法）。

- **每周一 → 周K 视角**：用周K 看**龙头相对强度与买点**（周线相对大盘超额、周成交量、细分龙头是否走出持续性），核对本清单指标在周线数据上的最新变化，输出「本周操作倾向」。
- **每月 1 号 → 月K 视角**：用月K 看**景气阶段与政策出清进度**（月度涨跌/量能、月线趋势、集采/医保/批文等催化事件进展），核对上一月的细分景气与政策风险，输出「本月持有/调仓倾向」。
- 本风格周期侧重：**月K 定产业景气与政策，周K 选龙头买点**；医药板块周内波动大（±5% 常见），不以单日表现定去留。
- 数据来源：本系统 `kline --klt 102`（周K）/ `klt 103`（月K）拉取；无周/月K 数据时明确标注「数据不足」，不以日K 模拟代替。
- 输出必须标注所看周期（周K 或 月K）与触发点（周一 / 月初），便于回看验证。

## 1. 风格画像

- 一句话：**长期重仓医药赛道，买高景气细分方向里的龙头，淡化短期波动**。
- 特征：行业极度聚焦（医药持仓占比常年很高）、偏好龙头与有壁垒的创新资产、随医药产业大周期做长线、基金规模大所以偏好大市值流动性好的标的。
- 行业偏好：创新药（CXO/出海授权）、医疗服务（眼科/口腔/体检）、医疗器械（高值耗材/设备国产替代）、疫苗、中药龙头。

## 2. 核心判断清单（可判定指标）

| 维度 | 标准 | 说明 |
|---|---|---|
| 细分景气 | 所处细分行业处于成长期（渗透率提升/需求扩容/政策友好） | 集采重压的仿药规避 |
| 创新壁垒 | 有管线/专利/平台/渠道壁垒，研发投入占比高 | 无壁垒跟风票回避 |
| 龙头地位 | 细分市占率前三，收入端增速 > 行业均值 | 只做龙头 |
| 收入质量 | 收入/利润增速稳定、经营现金流匹配 | 应收/存货异常要警惕 |
| 政策 | 不在集采/医保谈判核心冲击清单上，或已有政策出清 | 政策是医药最大变量 |

## 3. 选股规则

1. 只做**高景气细分 + 龙头 + 政策出清或友好**三者同时满足的标的。
2. 创新属性优先：管线进入收获期（报产/获批/放量）是最大催化。
3. 回避：纯仿制药已过高峰、集采份额占比大、研发管线单薄的标的。
4. 用「板块大 beta + 个股高 alpha」：板块景气向上时才重仓，景气向下时降低暴露。

## 4. 买 / 卖 / 持有纪律

- 买入：细分景气确认 + 龙头地位清晰 + 政策风险可控；回调分批，不追高。
- 卖出条件：① 核心管线/单品逻辑破坏（临床失败、获批不及预期）；② 集采/政策直接冲击主业；③ 细分景气明显下行；④ 涨幅已透支多年景气（估值到历史极高分位）。
- 持有：医药板块波动大（单日 ±5% 常见），用景气周期定位，不因单日大跌离场；但**逻辑破坏必须离开**。

## 5. 反例（何时不适用本风格）

- 非医药标的——本风格不跨行业。
- 纯题材炒作阶段（如医美概念无业绩支撑的连板）——不适用。
- 集采核心冲击、政策未出清的仿药/器械——风险大，回避。
- 需要短期博弈「明天涨不涨」——该风格是产业逻辑型，不适合。

## 6. 分析输出格式建议

1. **细分景气定位**：该标的所在细分所处产业周期（前期放量/平台期/出清期）。
2. **壁垒与龙头核对**：市占、管线进度、研发投入、准入壁垒。
3. **政策风险清单**：集采目录、谈判、医保支付逐项核对，缺数据明说。
4. **估值与位置**：当前估值分位、对应未来 2 年业绩兑现。
5. **操作倾向**：买入/持有/回避 + 跟踪的核心事件（临床数据、批文、集采公告）。
