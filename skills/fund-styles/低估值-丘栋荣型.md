> 本档案基于公开的基金经理风格总结整理（中庚丘栋荣：低估值价值投资、PB-ROE 框架），仅供参考、不构成投资建议。

## 1. 风格画像

- 一句话：**以显著低于内在价值的便宜价格买好一点的生意，等待价值回归**。
- 特征：深度逆向、全市场扫描、注重**安全边际**（跌不深），配置分散、持仓均衡；善于在中小市值、不被关注的角落里找机会。
- 行业偏好：地产链、煤炭/石油、银行、公用事业（红利）、医药/工业等**低估值+周期反转**方向；回避高估值抱团股。

## 2. 核心判断清单（可判定指标）

| 维度 | 标准 | 说明 |
|---|---|---|
| 估值 | PB 处于自身历史低位分位（如后 30%）、PE 显著低于行业均值 | 便宜是前提 |
| PB-ROE 匹配 | 「高 PB 需高 ROE、低 PB 容忍一般 ROE」：用 PB 与 ROE 的相对位置找错杀 | 核心框架 |
| 现金流/股息 | 自由现金流为正、股息率有吸引力（>3% 加分） | 真便宜 vs 价值陷阱 |
| 资产负债 | 低负债、无大额商誉/质押/爆雷风险 | 防价值陷阱 |
| 反转催化 | 行业或公司存在改善边际（政策、价格、供需拐点） | 便宜且变好 |

## 3. 选股规则

1. 只买**估值与基本面错配**的：要么便宜且稳定，要么便宜且正在变好；不碰「便宜但持续恶化」。
2. 分散：单行业/单票不过度集中，用小仓位组合对冲误判。
3. 逆向：人多的地方不去，买市场恐慌时错杀的优质资产。
4. 用 PB-ROE 象限图定位：左下（低PB低ROE）只看周期反转；右下（低PB高ROE）是熟面——重点猎场。

## 4. 买 / 卖 / 持有纪律

- 买入：估值进入历史低位 + 无硬伤（防陷阱）+ 存在改善边际；分多档买入下行空间有限。
- 卖出条件：① 估值回归至合理/偏高（PB 修复到中位以上）；② 基本面恶化（ROE 下滑、现金流转负）；③ 出现更好的低估值机会（调仓换股）。
- 持有：等待期可能很长，用股息/低波动扛住；不因「涨得慢」而换成高估值的抱团股。

## 5. 反例（何时不适用本风格）

- 高估值、讲长期故事但无当期现金流支撑的成长股/题材股——不适用。
- 纯题材连板、情绪博弈——与本风格无关。
- 「低估值陷阱」：持续亏损、资产负债恶化、行业长期下坡的便宜股——不是机会是坑。

## 6. 分析输出格式建议

1. **结论先行**：便宜吗？真便宜还是价值陷阱？
2. **PB-ROE 定位**：给出该标的在 PB-ROE 象限的位置与历史分位。
3. **防陷阱核对**：负债/商誉/现金流/大股东质押逐项过。
4. **催化与回归空间**：估值修复到目标位的空间与时间预期。
5. **操作倾向**：买入档位 / 持有 / 回避 + 放弃条件。
