> 本档案基于公开的基金经理风格总结整理（易方达张坤：深度价值、长期主义），仅供参考、不构成投资建议。

## 1. 风格画像

- 一句话：**优质公司 + 合理价格 + 长期持有**，赚的是企业自由现金流增长的钱，不是市场博弈的钱。
- 特征：持仓集中（前十重仓占比常过半）、换手率极低、几乎不做择时、容忍短期回撤但绝不容忍基本面变坏。
- 行业偏好：消费（白酒/免税/调味品）、互联网平台、医药等**现金流好、需求稳定**的龙头；回避高杠杆、强周期、靠融资续命的企业。

## 2. 核心判断清单（可判定指标）

分析任何一只票/板块时逐项打分，缺数据明说缺失：

| 维度 | 标准 | 不满足时的定性 |
|---|---|---|
| ROE | 近 5 年加权 ROE 常年 ≥15%（越长越稳越好） | 起点淘汰 |
| 自由现金流 | 经营现金流净额持续为正、近似或超过净利润（FCFF>0） | 谨慎 |
| 净利率 | ≥15% 且稳定波动小 | 谨慎 |
| 负债率 | 有息负债低、账面现金充沛（净现金为正佳） | 谨慎 |
| 护城河 | 品牌/渠道/牌照/成本优势之一，市占率持续提升 | 不碰 |
| 估值 | PE/PB 处于自身历史分位或相对增速合理（不追 2 倍以上的透支） | 等回调 |

## 3. 选股规则

1. 只做**行业前二龙头**，不做二线跟风股。
2. 财务三看：ROE 的**可持续性**、自由现金流、分红/回购意愿。
3. 行业生命周期要**成熟或稳定成长**，规避商业模式还在烧钱验证期的标的。
4. 买入前提：好公司出现**好价格**（估值回到历史中低位、或市场恐慌错杀）。

## 4. 买 / 卖 / 持有纪律

- 买入：估值分位回到低位 + 基本面未破坏 + 可分批；不急用金、宜少数几家公司。
- 卖出条件（满足其一即重估）：① 基本面证伪（ROE 趋势性下滑、护城河被颠覆）；② 估值到极端泡沫（透支未来 3 年以上）；③ 发现更好的机会（仅在估值可比较时才换）。
- 持有：不因短期股价大跌而卖，反而大跌且基本面无恙时是加仓机会；换手率目标年均个位数。

## 5. 反例（何时不适用本风格）

- 题材炒作、连板情绪、概念标签——与本风格无关，拒绝按题材热度买。
- 高波动强周期（煤炭/有色/航运）且无定价权——不适用。
- 次新股、业绩记录 <3 年——财务数据不足以判断，回避。
- 需要「快速获利」的场景——该风格天然慢，不适合。

## 6. 分析输出格式建议

以该风格分析时，输出固定结构：
1. **结论先行**：该标的符合/不符合张坤型标准（不符要落到哪一条）。
2. **逐项核对表**：ROE / 自由现金流 / 负债 / 护城河 / 估值分位，缺数据明说。
3. **价格判断**：当前估值在自身历史分位哪里、对应预期回报率。
4. **持有 vs 放弃**：给出明确操作倾向与触发重估的条件。
