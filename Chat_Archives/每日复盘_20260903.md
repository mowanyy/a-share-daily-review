- **根因已定**：GitHub Actions `schedule` 事件是"尽力而为"（官方文档明示高峰可延迟数十分钟到数小时，且低活跃/失败多会被降级）——实测复盘晚 10 小时、预案晚 7.5 小时。`workflow_dispatch` 走正常队列、几乎准时。**方案 = 外部精确 cron → 触发 workflow_dispatch**，仓库代码零改动（两个 workflow 本就有 dispatch 入口）。
- **Cloudflare 方案已落地（用户 2026-09-03 自行完成）**：Worker `daily-review-trigger`（贴入 dispatch 脚本）+ 机密 `DISPATCH_TOKEN`（fine-grained PAT，仅本仓库 Actions 读写，90 天有效期）+ 两条 Cron（`10 * * * *`＝北京18:00 复盘、`30 23 * * *`＝北京07:30 预案，均为 UTC）。原 GitHub schedule 保留作兜底，`push_state.json` 幂等防双推。
- **LLM 全链路已核验为官方 DeepSeek 单后端**：本地 `.env` 主三件套 `DEEPSEEK_API_KEY`/`LLM_BASE_URL=https://api.deepseek.com`/`LLM_MODEL=deepseek-chat`、兜底 key 为空；三个 push workflow 全部借用 secret `DEEPSEEK_FALLBACK_API_KEY`（存官方 key）作主用。SenseNova 仅剩历史注释/CHANGELOG/测试夹具，不参与生成。
- **公司网络直连 github.com 被墙**：本地代理 `127.0.0.1:7897` 可通；git push 必须 `git -c http.proxy=http://127.0.0.1:7897 push`（本轮提交 c5e3ef2 即如此推送成功）。
- **安全兜底已补**：`.gitignore` 新增 `pat.txt`、`data/*.db-wal`、`data/*.db-shm`（防令牌明文/SQLite 伴生文件误入库）；本轮无功能变更，未打版本 tag。

## 4. 核心代码/配置/数据锚点
Cloudflare Worker 触发脚本（`daily-review-trigger`，已部署，改动此脚本需在 Cloudflare 控制台 Edit code 后重新 Deploy）：
```javascript
// daily-review-trigger —— 到点触发 GitHub Actions 推送
// 闹钟（UTC）：10 * * * * = 北京 18:00 复盘；30 23 * * * = 北京 07:30 预案
// 需要机密：DISPATCH_TOKEN = github_pat_...
export default {
  async scheduled(event, env, ctx) {
    const now = new Date();
    const minutes = now.getUTCHours() * 60 + now.getUTCMinutes();
    if (minutes >= 600 && minutes <= 601) await dispatch(env, "push-review.yml");
    if (minutes >= 1410 && minutes <= 1411) await dispatch(env, "push-plan.yml");
  },
};

async function dispatch(env, workflow) {
  const url = `https://api.github.com/repos/mowanyy/a-share-daily-review/actions/workflows/${workflow}/dispatches`;
  const resp = await fetch(url, {
    method: "POST",
    headers: {
      Authorization: `Bearer ${env.DISPATCH_TOKEN}`,
      Accept: "application/vnd.github+json",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({ ref: "main" }),
  });
  if (!resp.ok) {
    console.error(`${workflow} dispatch failed: ${resp.status} ${await resp.text()}`);
  }
}
```
关键文件/配置位置：
- 本地密钥：项目根 `.env`（gitignored；兜底三件套留空 = 不触发兜底）
- 云端 workflow：`.github/workflows/push-review.yml` / `push-plan.yml` / `push-open.yml`（均已 DeepSeek 单后端）
- 推送幂等：`data/push_state.json`（重复触发不会双推）
- 环境网络：git/浏览器需走代理 `127.0.0.1:7897`（WinINET 系统代理）；内置浏览器（IAB）直连不通 GitHub
